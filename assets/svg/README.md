# 플랫폼 배지 자산

이 폴더의 다섯 SVG는 **공식 로고가 아닌 자체 제작 텍스트 배지**입니다.
64×24 viewBox, 어두운 배경, 읽을 수 있는 플랫폼명으로 통일했습니다.
2026-09-12에 assets/의 사용자 제공 PNG/JFIF/JPG 13개를 시각적으로 확인하고
어두운 배경에서의 녹색·청색·보라색·적색 계열을 참고했습니다. 원본 이미지를
추적해서 로고를 새로 그리거나 SVG 안에 래스터 이미지를 넣지 않았습니다.

확인한 공식 공개 경로:

- 치지직: https://chzzk.naver.com/ 및 https://help.naver.com/service/30044/category/7043?lang=ko
- SOOP: https://corp.sooplive.com/esg/2023/index.php?page=grow (CI 소개)
- Twitch: https://brand.twitch.com/ 및 https://legal.twitch.com/en/legal/trademark/
- RPlay: https://rplay.live/ 및 https://rplaylive.gitbook.io/rplay-userguide/helpcenter/faq
- YouTube: https://brand.youtube/ (기존 YouTube 브랜드 리소스 주소에서 이동)

공식 로고가 공개되어 있는 것과 이 저장소에서 변형·재배포할 수 있는 것은 별개입니다.
이번 조회에서는 일부 공식 페이지가 동적 화면/빈 본문으로 제공되어 구체적인 사용 조건과
재배포 가능한 원본 SVG 묶음을 검증하지 못했습니다. 사용자 제공 파일에도 라이선스 정보가
없어 요청된 대체 방식인 텍스트 배지를 채택했습니다. 이 기록은 사용 금지를 단정하는 것이
아니며, 향후 적합한 공식 SVG와 사용 조건을 확보하면 같은 파일명으로 교체할 수 있습니다.
플랫폼명과 상표의 권리는 각 권리자에게 있습니다.
