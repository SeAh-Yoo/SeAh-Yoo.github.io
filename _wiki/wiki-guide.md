이 항목은 위키 작성 방법을 보여 주는 안내입니다. 각 개념의 정의는 작성자가 직접 적고 다듬습니다.

## 개념 하나, 파일 하나 {#one-file}

`_wiki/` 폴더에 Markdown 파일을 추가합니다. 날짜가 없는 파일명을 사용하며, 이름을 바꾸지 않으면 페이지 주소도 유지됩니다.

```yaml
---
title: 개념 이름
description: 내가 생각하는 이 개념의 간략한 정의.
aliases: [다른 이름, 영문명]
last_modified_at: 2026-09-10
---
```

`title`은 필수입니다. `description`을 적으면 간략 설명 구역과 연결 링크가 자동으로 생깁니다. 별칭과 수정일은 필요할 때 추가합니다.

## 세부 설명과 목차 {#details}

본문에 `## 소제목`을 작성하면 문서 목차와 가나다 색인의 세부 설명 목록에 자동으로 나타납니다. `###`부터 `######`까지의 하위 제목도 지원합니다.

오랫동안 연결할 제목에는 `## 세부 설명 {#details}`처럼 고정 식별자를 붙일 수 있습니다. 제목을 고쳐도 식별자를 유지하면 기존 링크가 계속 동작합니다.

별도 페이지에 풀어 쓴 내용은 문서 상단의 `details`에 제목과 주소를 적습니다. 자세한 예시는 [위키 연결 안내]({{ '/wiki/wiki-links/' | relative_url }})에서 볼 수 있습니다.
